# 弹窗还原

依据截图 1:1 还原的两个站点首页弹窗，均为独立 HTML，直接用浏览器打开即可预览（建议手机视口 375px）。

| 文件 | 来源 | 说明 |
| --- | --- | --- |
| `zzy99-announcement.html` | https://vip.zzy99.cn/ | 「平台公告」弹窗 |
| `lcsup-trade-notice.html` | https://vip.lcsup.com/ | 「交易须知与合规规范」弹窗 |

## 说明

- 两个站点在当前网络环境下无法访问，无法抓取原始源码，样式与文案均按截图逐项还原。
- 截图中可见的文案已原样保留；截图外被裁切的部分在 HTML 中以 `（请补充：…）` 占位并加了 `<!-- TODO -->` 注释，替换文字即可。
- 点击右上角 × 或「我知道了」会关闭弹窗（给遮罩加 `hide` 类）。
